touch_app Ciclo de Vida de uma Requisição (Passo a Passo)

1

Recepção via Webhook Evolution API v2.3.7

O WhatsApp envia o JSON da mensagem para o endpoint /webhook do Cloud Run agents-runtime-test. O extract_envelope() normaliza o fileLength caso seja um protobuffer Baileys em formato dict.

2

Handshake Rápido & Registrador Ledger

O servidor verifica a idempotência no Firestore (message-processing/{id}). Se a mensagem for inédita, dispara um evento no Pub/Sub Topic e retorna 200 OK em menos de 180ms. Paralelamente, envia o indicador de digitação ("digitando...") no WhatsApp com delay_ms calculado.

3

Invocação LangGraph & Guardião Access Guardian

O worker de background abre um lease de 120s e executa o grafo LangGraph. Caso o usuário solicite mover uma reunião no calendário ou ler um e-mail, o access_guardian consulta a coleção usuarios/{phone} para validar os tokens e escopos OAuth ativos antes de liberar a chamada para calendar.move_event.

4

RAG Vetorial & Resposta com Personalidade Jennifier

Se a pergunta requisita conhecimento ou documentos anexados, o agent-knowledge-retriever realiza a busca vetorial k-NN (score >= 0.7) no agent-knowledge-v2. A Jennifier sintetiza a resposta final com sarcasmo sutil e profissionalismo técnico via DeepSeek V4 Flash.
